# UrbanLive 🌆

UrbanLive is a full-stack urban analytics platform that combines:

- 📍 Real-time AQI & weather data
- 🏙️ Livability Index scoring
- 💰 Machine learning-based real estate price prediction
- 🤖 AI-powered real estate chatbot assistant

## Features
- Interactive map (Leaflet)
- Location-based insights
- ML price prediction engine
- Clean React dashboard + FastAPI backend

## Tech Stack
- Frontend: React + Tailwind
- Backend: FastAPI
- ML: Scikit-learn
- Data: OSM + Kaggle datasets
